# General questions and answers

Some questions don't really fit anywhere, so I have put them in this section.

## My feature or change request is too specific, what do you mean by that?

Sometimes there is a feature request for Firefly III that could be a great addition to Firefly III, but it is just too specific. It is not useful for a reasonable number of users, or it solves a very specific problem for a small group of users.

Such requests are not honored. The requested change will not be made, and I will also not accept a PR to fix it.

A feature or an enhancement has to make peoples lives better by virtue of existing. For example, Firefly III allows you to quick-select a quarterly report range. The data importer connects to a variety of third party importers. That is useful. Even if you don't use it. You know what it does and why it is there.

An important check is if you first need to run into a problem to appreciate the requested feature. If it is not obviously to helpful or understandable to users who will never run into that problem, the feature is too specific.

The risk is that Firefly III or the data importer become a "jack of all trades, master of none".
